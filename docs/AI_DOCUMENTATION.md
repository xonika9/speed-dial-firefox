# Техническая документация: Speed Dial for Firefox

## 1. Обзор проекта

*   **Название:** Speed Dial for Firefox (speed-dial-xonika)
*   **Описание:** Браузерное расширение для Firefox, заменяющее стандартную страницу новой вкладки на настраиваемую панель быстрого доступа с плитками для сайтов и папок.
*   **Технологический стек:**
    *   **Фреймворк:** SolidJS
    *   **Язык:** TypeScript
    *   **Сборщик:** Vite
    *   **Маршрутизация:** @solidjs/router (hash-based)
    *   **Хранилище:** IndexedDB (основное) / browser.storage.local (резервное)
    *   **API браузера:** browser.bookmarks, browser.tabs, browser.storage

## 2. Архитектура приложения

### 2.1. Конфигурация и сборка
*   **`vite.config.ts`:** Конфигурация сборщика Vite. Использует плагин `solidPlugin` для компиляции SolidJS-компонентов. Ключевая настройка `build.target: 'esnext'` обеспечивает совместимость с последними стандартами JavaScript, что важно для браузерных расширений, работающих в современных окружениях.
*   **`tsconfig.json`:** Конфигурация TypeScript. Включает строгий режим (`strict: true`) для повышения надежности кода. Настройка `jsx: 'preserve'` указывает компилятору сохранять JSX-синтаксис для последующей обработки Vite, а `noEmit: true` означает, что `tsc` выполняет только проверку типов, а не компиляцию.

### 2.2. Точка входа и структура
*   **`src/index.tsx`:** Точка входа приложения. Монтирует корневой компонент `App` в DOM-элемент с id `root`. Оборачивает приложение в `Router` для обеспечения маршрутизации и `SettingsProvider` для предоставления глобального доступа к настройкам через контекст.
*   **`src/App.tsx`:** Основной компонент приложения. Содержит базовую разметку, включая `BackgroundWrapper` для управления фоном. Определяет маршруты (`/`, `/folder/:id`, `/help`) для навигации между главной страницей, папками и страницей помощи. Включает глобальные компоненты, такие как `ContextMenu` и `ConsentModal`, и управляет глобальными состояниями, например, блокировкой прокрутки страницы при открытии модальных окон.

### 2.3. Управление данными
*   **Хранилище приложения (`database.ts`):** Реализует гибридный подход к хранению данных. Основное хранилище — IndexedDB, используемое для кэширования изображений (фоны, иконки сайтов, миниатюры). `browser.storage.local` используется как резервное хранилище и для настроек. Структура включает `background_store` (фоновые изображения), `tile_image_store` (пользовательские изображения для плиток) и `favicon_store` (кэш иконок сайтов).
*   **API закладок (`bookmark.ts`):** Набор утилит для взаимодействия с `browser.bookmarks` API. Предоставляет функции для "read-only" доступа: чтение, поиск и обход древовидной структуры закладок. Операции записи (создание, изменение, удаление закладок и папок) вызываются напрямую из UI-компонентов в ответ на действия пользователя.

## 3. Ключевые компоненты (UI)

*   **Плитки (`Tile.tsx`, `BookmarkTile.tsx`, `FolderTile.tsx`):**
    *   `Tile.tsx`: Базовый компонент плитки, отвечающий за общую структуру, стили и обработку событий (клик, контекстное меню).
    *   `BookmarkTile.tsx`: Отображает плитку для закладки. Показывает либо скриншот страницы, либо пользовательское изображение, либо текстовое представление. Предоставляет функциональность для перехода по ссылке и вызова контекстного меню с действиями.
    *   `FolderTile.tsx`: Отображает плитку для папки. Показывает сетку миниатюр (до 4-х) из содержимого папки. Обрабатывает навигацию внутрь папки по клику.
*   **Панели (`Toolbar.tsx`, `Sidebar.tsx`):**
    *   `Toolbar.tsx`: Настраиваемая верхняя панель инструментов. Содержит кнопки для часто используемых действий, таких как добавление новой плитки, поиск и доступ к настройкам. Состав кнопок может настраиваться пользователем.
    *   `Sidebar.tsx`: Боковая панель, открывающаяся для доступа к глобальным настройкам приложения: выбор темы (светлая/темная), настройка фона, изменение размеров и отступов плиток.
*   **Интерактивные элементы (`ContextMenu.tsx`, `Modal.tsx`):**
    *   `ContextMenu.tsx`: Универсальный компонент для создания контекстных меню. Позиционируется относительно точки клика и отображает список действий, переданных ему в качестве дочерних элементов.
    *   `Modal.tsx`: Универсальный компонент для модальных окон. Использует `Portal` из SolidJS для рендеринга содержимого поверх остального интерфейса, обеспечивая фокус и изоляцию.

## 4. Вспомогательные утилиты (`src/utils/`)

*   **`image.ts`:** Утилиты для работы с изображениями. Включают функции для загрузки изображений с URL, создания скриншотов активной вкладки (`retrievePageScreenshotImage`), и изменения размера изображений (`scaleDown`) для создания миниатюр.
*   **`visual.ts`:** Управляет визуальным представлением плиток. Отвечает за загрузку и кэширование изображений, а также за генерацию стандартных представлений (цветной фон + инициалы сайта), если изображение недоступно.
*   **`filter.ts`:** Содержит утилиты для работы с событиями и фильтрами, например, для комбинирования нескольких обработчиков событий в один.
*   **`assorted.ts`:** Коллекция разнообразных вспомогательных функций: `debounce` для ограничения частоты вызовов функций, `clamp` для ограничения числа в диапазоне, утилиты для работы с URL и кодирования/декодирования Blob-объектов в Base64.
*   **`rand.ts`:** Утилиты для генерации детерминированных псевдослучайных чисел и цветов на основе строкового сида (например, URL сайта). Это позволяет получать одинаковые "случайные" цвета для одних и тех же сайтов при каждом запуске.

## 5. Порядок работы (Workflow)

1.  **Инициализация:** `src/index.tsx` монтирует компонент `App` и предоставляет ему `Router` и `SettingsProvider`.
2.  **Отображение:** `App.tsx` анализирует текущий URL. Для корневого маршрута (`/`) или маршрута папки (`/folder/:id`) он рендерит компонент `Folder` и `Sidebar`.
3.  **Загрузка данных:** Компонент `Folder` использует утилиты из `bookmark.ts` для асинхронного получения данных о закладках и подпапках из `browser.bookmarks` API для текущего уровня иерархии.
4.  **Рендеринг плиток:** `Folder` итерирует по полученным данным и для каждого элемента (закладки или папки) рендерит компонент `Tile`, который, в свою очередь, делегирует рендеринг конкретному типу плитки: `BookmarkTile` или `FolderTile`.
5.  **Загрузка визуала:** Компоненты плиток используют утилиты из `visual.ts` и `image.ts` для асинхронной загрузки или генерации изображений. Процесс включает проверку кэша в IndexedDB и, в случае отсутствия, загрузку или создание нового изображения.
6.  **Взаимодействие:** Пользователь взаимодействует с интерфейсом через `Toolbar` (добавление сайтов), `Sidebar` (настройка внешнего вида) и `ContextMenu` (действия с плитками). Эти действия вызывают модальные окна (`Modal`) или напрямую обращаются к `browser.bookmarks` API для изменения данных.
